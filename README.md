# Carolina Alcântara — Advocacia e Consultoria Jurídica

Site institucional desenvolvido em React para apresentar a atuação de Carolina Alcântara em Direito Tributário, Direito Empresarial e consultoria jurídica preventiva.

O projeto utiliza uma direção visual minimalista baseada na identidade vinho e creme da marca. O fundo combina luz suave e arcos lineares inspirados no ambiente do escritório e no monograma `CA`.

## Recursos

- Layout responsivo para computador e celular.
- Abertura animada com o logotipo.
- Áreas de atuação com conteúdo interativo.
- Animações de entrada acionadas pela navegação.
- Movimento dos círculos sincronizado com a rolagem.
- Respeito à preferência `prefers-reduced-motion`.
- Seções de apresentação, atendimento e contato.

## Tecnologias

- React
- Vite
- JavaScript
- CSS

## Executar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção:

```bash
npm run build
```
